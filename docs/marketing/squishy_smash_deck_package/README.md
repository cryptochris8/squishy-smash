# Squishy Smash Licensing & Manufacturing Deck

This folder is a complete Claude Code handoff package for creating a professional licensing and manufacturing presentation for the Squishy Smash brand.

## Primary Goal
Create a polished presentation that introduces Squishy Smash as a developed children's character IP and communicates readiness for:

- Custom squishy toy prototyping
- OEM/ODM manufacturing discussions
- Licensing discussions
- Retail and distribution introductions
- Strategic partnerships

## What Claude Code Should Do
1. Read every file in the `docs/` folder.
2. Inspect the `assets/` folder for brand art, logos, book photos, character renders, screenshots, and 3D model previews.
3. Build a professional 16:9 presentation.
4. Export the final deck as both:
   - `output/Squishy_Smash_Licensing_Manufacturing_Deck.pptx`
   - `output/Squishy_Smash_Licensing_Manufacturing_Deck.pdf`
5. Use placeholders only when a required asset is unavailable.
6. Keep all editable source files in the project folder.

## Preferred Build Options
Use whichever presentation-generation method is most reliable in the active environment:

- PptxGenJS
- Python-pptx
- Google Slides API
- HTML/CSS to PDF plus PPTX recreation

PptxGenJS is preferred when available because it provides strong control over layout and editable output.

## Important
The deck should feel like a real brand opportunity, not a school presentation. It should be visual, premium, colorful, and concise.
