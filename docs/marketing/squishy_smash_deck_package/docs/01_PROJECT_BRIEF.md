# Project Brief

## Project Name
Squishy Smash Licensing & Manufacturing Deck

## Brand Summary
Squishy Smash is an original children's character universe built around 48 unique squishy characters. The brand already includes:

- 48 original characters
- Consistent 2D character artwork
- 3D character models
- A character book with collectible trading cards
- A children's storybook
- An iOS app
- A Roblox game

The presentation should communicate that Squishy Smash is not merely a toy idea. It is an existing multi-format intellectual property with physical, digital, publishing, and gaming extensions.

## Primary Audience
- Custom squishy toy manufacturers
- OEM and ODM toy factories
- Licensing agents
- Retail buyers
- Toy distributors
- Consumer product partners

## Main Objective
Persuade potential partners that Squishy Smash is ready to move into physical collectible squishy toys and that the existing brand assets reduce product-development risk.

## Core Message
The characters, artwork, stories, cards, games, and 3D models already exist. The next logical step is converting selected characters into real-world collectible squishies.

## Desired Tone
- Professional
- Imaginative
- Energetic
- Kid-friendly
- Commercially credible
- Premium but approachable

## Avoid
- Overly childish layouts
- Dense paragraphs
- Generic corporate stock imagery
- Claims that cannot be proven
- Revenue projections presented as guarantees
- Statements implying existing retail partnerships unless documented
