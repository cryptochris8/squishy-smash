# Asset Checklist

Place available files into the `assets/` folder using clear names.

## Highest Priority
- Squishy Smash logo, transparent PNG or SVG
- Storybook front cover
- Storybook interior spread photos or exports
- Character book front cover
- Trading card examples
- 8 to 12 best character renders
- Screenshots from Roblox
- Screenshots from the iOS app
- 3D model turntable renders or front/side/back views

## Helpful Additional Assets
- All 48 character thumbnails
- Brand website screenshot
- App Store screenshot
- Roblox game page screenshot
- Character names and rarity levels
- Existing packaging ideas
- Author photo, only if desired
- Studio logo

## Naming Convention
Use names such as:
- logo_squishy_smash.png
- storybook_cover.jpg
- character_book_cover.jpg
- trading_card_character_name.png
- character_character_name_front.png
- character_character_name_3d.png
- roblox_gameplay_01.jpg
- ios_app_01.png

## Placeholder Rules
When an asset is missing:
- Use a labeled placeholder box
- State the exact asset needed
- Do not invent official character art
- Do not substitute unrelated cartoon characters
