# Design System

## Overall Visual Style
The deck should feel like a polished toy-brand pitch: bright, tactile, playful, and commercially credible.

## Format
- 16:9 widescreen
- Recommended size: 13.333 x 7.5 inches
- Strong visual hierarchy
- One major idea per slide

## Color Direction
Use colors derived from the official Squishy Smash logo and character art whenever available.

Suggested fallback palette:
- Deep purple: #5B3FD6
- Bright pink: #FF5CA8
- Aqua: #35D0C6
- Sunny yellow: #FFD65A
- Soft cream: #FFF8EE
- Dark ink: #24213A

Do not use the fallback palette if official brand colors are supplied.

## Typography
Preferred:
- Headings: Fredoka, Baloo 2, or Nunito ExtraBold
- Body: Nunito, Inter, or Aptos

Use common fallback fonts when custom fonts are unavailable. Do not package or redistribute font files.

## Layout Principles
- Large character art
- Rounded shapes
- Soft blobs and organic frames
- Subtle shadows
- Minimal body copy
- Plenty of white or open space
- Avoid crowded slide layouts

## Image Treatment
- Use transparent PNG character renders when possible
- Preserve character proportions
- Do not crop faces or key features
- Use consistent lighting and scale
- Avoid random stock photos unless showing manufacturing processes

## Charts and Diagrams
Prefer simple icon-based diagrams and labeled process flows. Avoid unnecessary charts.

## Footer
Small footer may include:
Squishy Smash | Confidential Concept Presentation

Do not mark confidential if the user intends broad public distribution. Make this easy to remove.
