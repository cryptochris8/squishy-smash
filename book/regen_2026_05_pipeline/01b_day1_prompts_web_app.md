## Quick reminder — what to watch for as candidates come back

- **Character recognition:** does the new chalk-pastel character read as the same Soft Dumpling / Goo Ball / Blushy Bun Bunny as the source card? If not, the Image Prompt isn't holding — raise its weight if there's a slider, or re-upload.
- **Style cohesion:** all candidates across all 18 prompts should look like they came from the same illustrator. If style drifts wildly, the Vashti Harrison Style Reference isn't anchoring — verify it's still attached for every prompt.
- **No AI tells:** mushy eyes, mirror highlights, extra limbs. If a candidate is otherwise great but has one tell, keep it — you'll fix in the hand-paint pass later.
